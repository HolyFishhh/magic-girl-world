# 初始战斗内容修复

仅在收到 `[战斗内容修复]` 时执行。`问题=` 后是程序给出的字段路径与错误码，不是新变量；按路径修正，不要复制、解释或写回该行。

重新生成一套与当前角色身份、职业和既有开场设定一致的初始战斗内容，只替换：

- `battle.core.hp/max_hp/lust/max_lust/card_removal_count`、`battle.level`、`battle.exp`
- `battle.cards/artifacts/items/statuses`
- `battle.player_abilities/player_status_effects/player_lust_effect`

保持剧情事实和 `status/factions/npcs` 不变；禁止修改 `run/run_result/run_upgrade/reward/enemy`，不生成 Option 或 `<BATTLE_START>`。输出一句简短过渡正文，再输出一个 `<UpdateVariable>`。

使用 `_.set` 先把需要重建的数组设为 `[]`，再用 `_.assign` 逐项写入完整对象。新内容只使用浅层 `effects`，不得输出旧 `effect`、`description` 或内部 AST。总 `quantity` 至少 10，必须有基础 3 能量可打出的牌、稳定胜利手段、防御或恢复、至少一个遗物、至少一个道具和玩家欲望满溢效果；引用的新状态必须在同一回复完整注册。
