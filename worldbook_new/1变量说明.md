# 变量路径地图

路径均相对于 `stat_data`。这里只说明长期数据放在哪里；卡牌、状态、遗物、道具和敌人的完整对象格式由按关键词激活的“战斗内容生成要求”说明，普通剧情不要重复生成这些对象。

```json
{
  "status": {
    "time": "YY年MM月DD日 HH:mm",
    "location": "地点名称（具体位置）",
    "profession": {"name":"职业名","ability":"卡牌能力风格"},
    "permanent_status": [{"name":"名称","description":"描述"}],
    "temporary_status": ["短期状态名"],
    "clothing": {
      "head":"","neck":"","hands":"","upper_body":"",
      "lower_body":"","underwear":"","legs":"","feet":""
    },
    "inventory": ["非战斗剧情物品"]
  },
  "battle": {
    "core": {"hp":100,"max_hp":100,"lust":0,"max_lust":100,"card_removal_count":0},
    "cards": [],
    "artifacts": [],
    "items": [],
    "statuses": [],
    "player_abilities": [],
    "player_status_effects": [],
    "level": 1,
    "exp": 0,
    "enemy": {},
    "player_lust_effect": {}
  },
  "factions": {
    "player_alignment":"绝对中立",
    "invasion":0,
    "relations":[{"name":"势力名","reputation":0,"status":"中立","note":"备注"}]
  },
  "npcs": {
    "npc_id": {
      "name":"姓名","tracking":true,"current_action":"当前行动",
      "affection":0,"affection_level":"关系阶段","alignment":"阵营",
      "relationship":"与玩家关系","other_npc_relations":"其他关系",
      "level":1,"appearance":"外貌","abilities":"能力","battle_style":"战斗风格"
    }
  },
  "reward": {"card":[],"artifact":[],"item":[],"limits":{"cards":1,"artifacts":1,"items":1}},
  "game_mode": "story | expedition",
  "run": null,
  "run_result": null,
  "run_upgrade": null

```

## 边界

- `status.inventory` 只放剧情物品；战斗消耗品放 `battle.items`。
- `battle.cards/artifacts/items/statuses` 是持久内容；`player_abilities/player_status_effects/enemy` 只属于本场战斗。
- `battle.level` 由程序根据经验结算，禁止直接修改。`battle.exp` 是当前等级进度，升级需求为 `100+50*(n-1)`。
- 卡牌稀有度为 `Common, Uncommon, Rare, Epic, Legendary, Corrupt`；遗物为 `Common, Uncommon, Rare, Boss, ENS`。新内容只生成浅层 `effects`，不得生成旧 `effect` 或内部 AST。
- `stat_data.battle` 必须保持为对象；生命、欲望和上限是有限 number，数组不得字符串化。平铺 `battle` 不属于当前协议。
- `factions.invasion` 是 0-7 整数。NPC 只登记有姓名且会持续登场的重要人物。
- `reward` 只放待选择候选；确认后程序会迁移并清空。
- `run` 是可选远征模式的程序存档，默认 null，AI 禁止修改。`run_result/run_upgrade` 只在玩家已主动开启远征且对应协议按需激活时临时写入。
- `game_mode` 由开始页程序写入，只读；剧情模式为 `story`，远征模式为 `expedition`。
