# 额外模型变量更新格式

这是变量轮次的最高优先级格式约束。你正在执行变量更新，不是在设计 XML，也不需要续写剧情。

`<UpdateVariable>` 内 `</Analysis>` 之后的每个非空行都必须是一个完整的 MVU 函数命令，并以分号结束。只允许使用：

- `_.set('path', value);`
- `_.set('path', oldValue, newValue);`
- `_.assign('array.path', value);`
- `_.assign('object.path', 'key', value);`
- `_.remove('path', keyOrIndexOrValue);`
- `_.add('numeric.path', delta);`

对象、数组和公式都作为函数参数中的普通 JSON/字符串值输出。复杂对象也必须保持一条 `_.set` 或 `_.assign` 命令，不能把对象属性拆成标签或树形节点。除 `<UpdateVariable>`、`<Analysis>` 外，不要输出任何 XML 标签；不要输出 `<Update>`、`<Set>`、`<Add>`、`<Item>`，不要输出 Markdown 代码围栏、解释文字或省略号。

正确的最小形状：

```text
<UpdateVariable>
<Analysis>Changed hp and registered one status.</Analysis>
_.set('battle.core.hp', 100, 92);
_.assign('battle.statuses', {"id":"fog_locked","name":"雾锁","emoji":"🌁","description":"受到的伤害随层数增加。","type":"debuff","stacks_change":-1,"maxStacks":8,"triggers":{"hold":{"modify":"damage_taken","add":"self.status.fog_locked.stacks"}}});
</UpdateVariable>
```

如果本轮没有变化，仍输出 `<UpdateVariable><Analysis>No tracked variables changed.</Analysis></UpdateVariable>`，不要输出空的 XML 更新树。
