# 首条消息初始化

仅在第一次回复后的额外模型解析中执行。用户会发送 `[角色创建]` 后的一行浅层 JSON，并以 `[剧情模式]` 或 `[远征模式]` 和 `[开始游戏]` 结束；结合主模型刚生成的开场剧情，读取 `mode/name/faction/ordinary/supernatural/city/location/note`。只输出一个 `<UpdateVariable>`，不续写或改写开场正文，不输出选项或战斗启动标记。变量路径均相对于 `stat_data`，遵循“MVU 变量更新协议”。

## 必须初始化

1. `status`：时间、地点、职业 `name/ability`、永久/临时状态、固定八个服装部位、剧情物品。
2. `battle.core`：当前/最大生命、当前/最大欲望、删卡次数。默认上限 100，可按角色设定小幅调整。
3. `battle.cards`：与角色职业和背景一致的主题卡组。
4. `battle.artifacts/items`：1-2 个有实际联动的初始遗物及合理的初始道具。
5. `battle.player_lust_effect`：玩家使敌人欲望满溢时触发的效果。
6. `battle.statuses`：上述内容引用的每个自定义状态都必须完整定义。
7. `battle.level/exp`：无明确强者设定时为 1/0；经验是当前等级内进度。
8. `factions.player_alignment/invasion/relations`：入侵强度是 0-7 整数，无相关剧情时为 0。
9. `npcs`：仅登记开场已出现并会持续登场的重要人物；普通敌人和路人不登记。

`run/run_result/run_upgrade` 由状态栏按需处理，首轮禁止输出相关命令。`game_mode` 由开始页程序写入，AI 不要创建或修改；剧情模式的 `run` 保持 null，远征模式在起始战斗内容通过门禁后由程序创建。不得自行输出 `[路线节点]`。

## 初始牌组

- 总 `quantity` 至少 10。通常生成 5 张基础攻击、5 张基础防御、1-3 张各一张的核心牌。
- 基础牌简单可靠，核心牌体现一个清晰构筑方向；卡组必须同时有稳定胜利手段和防御手段。
- 每个对象完整输出，ID 唯一且只用字母、数字、下划线；不得用中文名充当 ID。
- 新内容只使用 `effects`，不得同时生成旧 `effect`、内部 AST 或字符串化 JSON。
- 卡牌、遗物、道具、能力、欲望效果和状态不写 `description`；程序会从结构化规则生成显示文本。
- 自定义状态先设计完整定义，再让卡牌、遗物、道具或欲望效果引用；不得留下未注册 ID。
- 欲望构筑要能可靠累积欲望，并在敌人 1-3 次满溢内产生足以推进胜利的收益。

## 初始化示例

此示例只展示命令形状。实际内容必须根据 {{user}} 和开场剧情重新设计。

```text
<UpdateVariable>
  <Analysis>Initialize the character, themed deck, combat resources, and world state.</Analysis>
  _.set('status.time', '', '2030年07月18日 02:15');
  _.set('status.location', '', '白木市（旧天文台）');
  _.set('status.profession.name', '', '影术师');
  _.set('status.profession.ability', '', '以暗影蓄势，并用护幕维持节奏');
  _.set('battle.core.hp', 100, 80);
  _.set('battle.core.max_hp', 100, 80);
  _.set('battle.core.lust', 0, 0);
  _.set('battle.core.max_lust', 100, 100);
  _.set('battle.core.card_removal_count', 1, 1);
  _.assign('battle.cards', {"id":"shadow_strike","name":"暗影斩","emoji":"🌑","type":"Attack","rarity":"Common","cost":1,"quantity":5,"effects":{"damage":6}});
  _.assign('battle.cards', {"id":"umbral_guard","name":"幽幕防护","emoji":"🛡️","type":"Skill","rarity":"Common","cost":1,"quantity":5,"effects":{"block":5}});
  _.assign('battle.cards', {"id":"whisper_focus","name":"低语专注","emoji":"👁️","type":"Power","rarity":"Rare","cost":1,"quantity":1,"trigger":"turn_start","effects":{"draw":1}});
  _.assign('battle.artifacts', {"id":"whispering_tome","name":"低语魔典","emoji":"📖","rarity":"Common","trigger":"battle_start","effects":{"block":2}});
  _.assign('battle.items', {"id":"minor_tonic","name":"微光药剂","emoji":"🧪","count":1,"effects":{"heal":10}});
  _.set('battle.player_lust_effect', {"name":"暗影汲取","effects":{"damage":8,"heal":5}});
  _.set('battle.level', 1, 1);
  _.set('battle.exp', 0, 0);
  _.set('factions.player_alignment', '绝对中立', '绝对中立');
  _.set('factions.invasion', 0, 0);
</UpdateVariable>
```

服装八个固定部位应分别 `_.set`；数组内容逐项 `_.assign`。没有状态、势力关系或 NPC 时保持初始化空结构，不要生成占位对象。
