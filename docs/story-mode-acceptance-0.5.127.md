# 剧情模式真实两阶段验收：0.5.127

## 验收范围

在本地 SillyTavern `127.0.0.1:8012` 中使用玩家已导入的剧情预设和当前 DeepSeek Flash 连接，按真实职责边界连续验证：主模型只写剧情，MVU 第二阶段只写变量；覆盖首轮初始化、普通增量、自然遇敌、战斗内容预检、程序结算、战后奖励、奖励领取和持久成长。

- SillyTavern：1.18.0

## 连续结果

| 阶段 | 结果 |
| --- | --- |
| 首轮初始化 | 3 个卡牌定义、总数量 12、1 遗物、1 道具、玩家欲望效果和完整核心数值；初始化门禁通过 |
| 普通剧情轮 | 只增量更新剧情状态与 NPC；卡牌、遗物、道具和欲望效果指纹保持不变；没有误注册敌人 |

| 战后成长 | 程序结算 25 经验；第二阶段生成 3 张卡牌候选、1 个道具候选及精确领取上限 |
| 奖励领取 | 领取 1 张卡和 1 个道具后，牌组总量 12→13、道具种类 1→2；候选和限制全部清空 |

## 本轮修复

- 状态应用/移除允许模型偶发输出语义明确的 `{id, stacks, to}` 浅层对象，内部转为规范同级字段；冲突字段、未知键和未注册状态仍拒绝。
- 一个 `scry` 或 `seek` 可与常见数值效果同处浅层对象，编译器按固定顺序内部拆分；多个牌区操作仍必须使用数组，避免猜测先后语义。
- 真实验收器与锁定 MVU 的解析行为对齐：当开标签与命令完整但只缺结束标签时，按 MVU 实际行为规范化；残缺命令和非法 JSON 不放行。
- 首轮改用多条短 `_.assign` 初始化卡牌、遗物和道具，降低单条超长数组被模型截断或多写括号的概率。

原始模型正文和变量结果保存在本地忽略文件 `real-story-loop-0.5.126.log`，其中不保存 API Key。发布版本改名为 `0.5.127`，以避免 SillyTavern 同名角色缓存污染。
