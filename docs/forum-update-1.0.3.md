## 1.0.3（角色卡与设计辅助器 1.0.3）

- 恢复剧情模式原有的自由剧情状态栏与行动布局，包括人物记录、衣物、背包、剧情状态、势力关系、卡组、遗物与道具，不再被爬塔界面接管。
- 剧情正文继续由酒馆消息原生显示，不会被状态栏替换或额外复制；需要战斗时在正文后显示新版战斗页面，战斗底部仍使用剧情状态栏。
- 剧情状态栏补全能力、战斗状态、资源、欲望效果、姿态和召唤成长；欲望效果保持可选，空模板不会阻止战斗。
- 修复部分模型同时输出合法卡牌效果和空拼写污染时无法战斗的问题，实际未知内容仍会正常提示错误。
- 手机端统一使用小扑克牌布局：390px 可完整显示四张并露出第五张，540px 可完整显示五张；战斗、三选一和两种状态栏保持同一尺寸，完整规则可通过卡面滚动与“详情”查看。
- 优化手机战场、敌我信息、牌堆和底部工具布局，减少顶部空白并保留多敌人与召唤物显示。
- 爬塔战后剧情默认开启，会根据已经结算的战斗日志生成正文并保留在历史中；后续节点不必等待正文生成完成。
- 爬塔剧情块新增“展开全部/收起”，默认紧凑显示，展开后可直接阅读完整当前剧情。
- 修复后台生成与战斗、奖励、路线图切换的时序问题，避免页面已经切换后才丢失战后剧情或被迟到界面覆盖。
- 停止自动转换旧 expedition 模式和旧扩展安装方式。请保留旧卡与原存档，在新卡中重新开局体验当前模式和内容协议。

请导入并选择 `魔法少女世界 1.0.3`，同时将“魔法少女世界设计辅助器”更新到 `1.0.3` 后刷新整个酒馆页面，并确认使用新卡内嵌的世界书。更新不会自动生成剧情、推进或改写玩家存档。
