# 0.5.93 更新记录

## 普通剧情主线

- 修复开始页在 MVU 尚未完成聊天级初始化时就触发首轮生成，导致额外模型错过第一个 `MESSAGE_RECEIVED`、开局变量没有生成的问题。
- 开始页会先确认酒馆助手、MVU、内嵌世界书和当前楼层初始变量已就绪；任一环节失败时不再带病发送首轮消息，可直接重试。
- 修复“首条消息变量更新”只扫描当前助手楼层、看不到上一条 `[开始游戏]` 用户消息的问题，扫描深度固定为两层。
- 移除状态栏中的强制战斗按钮。用户可以随意输入自然语言行动；是否进入战斗由剧情发展决定，主模型在确实开战时自动输出 `<BATTLE_PENDING>`，随后才由 MVU 额外模型注册战斗数据。

## MVU 配置

- 角色级 `[config_override]` 只保留 MagVarUpdate 正式支持的字段：额外模型解析、自动请求和 `[mvu_update]` 世界书白名单。
- 兼容假流式和“模型来源=与插头相同”改由卡内加载器首次安装时写入全局 MVU 设置，避免配置文件显示已设置、实际却未进入有效配置。

## 后续记录

- 远征模式后续改为首次设置时激活专用世界书，不再依赖用户每轮输入控制标记。
- 普通剧情与未来远征均保持用户输入自由；按需调用额外模型的完整机制留待远征协议重构时统一设计。

## 验证

- 完整发布门禁通过；最终卡已通过 SillyTavern 官方接口导入并链接内嵌世界书 `魔法少女世界0.5.93`。
- 导入后的世界书确认包含 17 条，首条初始化条目的实际扫描深度为 2。
- 普通剧情状态栏实机确认只有自由输入和发送按钮，没有强制战斗入口。
- 当前本地酒馆未连接模型 API，因此在线双模型回复仍需在已配置模型的酒馆中确认；代码不会再在 MVU 未就绪时发送首轮消息。
