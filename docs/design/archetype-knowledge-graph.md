# 卡牌流派知识图谱

## 定位

流派图谱描述机械循环和演化关系，不描述题材。相同运行时结构即使分别表现为不同元素、诅咒、武术或魔法，也属于同一机械家族；只有准备方式、转换方式、收益时机或风险结构不同，才拆成不同流派。

权威实现位于 `src/game-core/archetypeGraph.ts`。当前图谱包含 62 个节点，覆盖直接输出、状态、欲望、防护、恢复、牌区、费用、资源、成长、召唤、多目标和规则控制等主要机械域。

## 核心模型

每个节点包含：

- 稳定 ID、中文标题和机械说明；
- 建立循环所需的最小特征；
- 提升亲和度但不强制存在的可选特征；
- 区分“只有准备”与“已经形成收益”的收益特征；
- 通用内容角色与实际机械冲突；
- 相邻节点、转向成本和缺失的桥接特征。

特征只来自统一 DSL：操作、机械轴、目标、牌区、触发器、状态关系、资源关系和复杂度。显示名称、描述、emoji、稀有度皮肤、职业与世界观不参与匹配。

## 节点族群

图谱按机械关系自然形成以下簇，而不是互斥分类：

- 输出与终结：直接压制、多段连击、倍率爆发、斩杀终结、残血爆发；
- 状态与延迟：状态积累、持续伤害、状态引爆、状态转化、状态成长、敌方状态反哺；
- 欲望与双轴：欲望压制、欲望溢出、欲望转化、双轴压制；
- 防护与生命交换：格挡循环、格挡留存、格挡转化、反击、恢复循环、恢复转化、自伤交换；
- 牌序与牌区：抽牌引擎、快速轮转、弃牌引擎、弃牌收益、消耗引擎、消耗回收、弃牌堆回收、牌顶控制、牌库精简；
- 费用与出牌：零费连锁、费用操纵、X 费爆发、保留蓄势、回响连锁、自动出牌、出牌触发、命中触发；
- 长期能力与资源：持续能力、延迟收益、资源引擎、资源蓄积、资源兑现、多资源编织；
- 卡牌演化与风险：衍生牌、卡牌成长、附魔构筑、负面附着、诅咒利用、牌库污染；
- 独立容器：姿态切换、Orb 循环、召唤协同、召唤群攻、召唤献祭；
- 战场与规则：多目标压制、意图反制、规则控制、拖延控制、额外回合、随机博弈。

节点可以跨簇连接。卡牌也可以同时支持多个节点。

## 单卡与整副牌组

单张卡先根据自身可执行字段计算多个亲和度；若引用自定义状态，再把对应状态定义的机械信号展开后计算。整副牌组按卡牌数量、遗物、能力和活动状态加权汇总，输出：

- 每个流派的分数和占比；
- 支持该流派的卡牌；
- 尚缺失的收益端；
- 通用散卡占比；
- 每张卡自己的多流派分布；
- 当前主轴、低成本桥接和相邻演化建议；
- 机械指纹。

普通状态页把整组占比显示为分段条，并展示相邻演化。它是观察工具，不是构筑限制。

## 奖励驱动

奖励候选可以有四种作用：

1. 深化已有主轴；
2. 补上已有准备端缺少的收益端；
3. 通过一个相邻节点进行桥接；
4. 作为不绑定流派的通用散卡提高稳定性或选择空间。

不允许只看最高占比生成同类卡，也不建议跨越多个不相邻节点突然转成无关构筑。每次奖励是在调整流派向量，而不是给牌组贴唯一职业标签。

## 扩展流程

新增一到两个运行时机制时，使用个人 Skill `maintain-card-archetype-graph`：

1. 从运行时能力提取通用机械特征；
2. 判断它扩展现有节点，还是形成新的准备/转换/收益循环；
3. 同时补充相邻演化和桥接成本；
4. 增加多亲和、换皮不变与反例测试；
5. 运行 Skill 自带审计脚本和项目回归。

审计完成时 `uncovered_operations` 必须为空。纯叙事、派生信号、语义依赖目标的绝对赋值以及仅用于敌方创作的操作会单独列入 `intentionally_unscoped_operations`，保留可见性但不会被强制包装成玩家流派；新增豁免必须说明理由。

不要在世界书中写具体卡牌或敌人例子；图谱只向第二阶段提供流派名称、简短说明、占比、缺口和演化方向，避免生成模型对固定范本产生依赖。

## 验收不变量

- 节点 ID 唯一且稳定；
- 无自环、悬空边或重复边；
- 题材换皮和等价状态换名不改变分布；
- 一张复杂卡可以获得多个亲和度；
- 相邻但不满足必要条件的机械不会误命中；
- 所有演化建议都来自真实图边；
- 通用散卡始终被允许；
- 新图谱不要求固定防御、治疗、攻击比例或牌组数量。
