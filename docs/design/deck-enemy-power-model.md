# 卡组与敌人程序化评分模型

## 目标

本模型给剧情模式提供一个可解释、可回归的数值基线。它不替代玩家创造、剧情事实或完整战斗引擎，也不把“有防御、有治疗、固定牌数”设为合格门槛。程序回答三个问题：

1. 当前长期构筑在标准压力下能做什么；
2. 指定难度的敌人应落在哪些共享预算内；
3. 已生成敌人在保留身份与机制的前提下，是否需要做确定性数值校准。

## 数据流

```text
玩家长期内容
  -> 多回合分布与六类探针模拟
  -> mwg.deck-power/v2
  -> 10/50/80/100/110% 难度
  -> mwg.enemy-budget/v2
  -> 第二阶段 MVU 生成敌人
  -> 程序契约校验
  -> 可选的确定性数值校准
  -> 实战结果与谱系记忆
  -> 下一次设计上下文
```

`battle.design_context` 是程序所有、AI 只读的长期变量。剧情模型只读紧凑 `brief`；负责修改变量的第二阶段模型读取完整对象。

## 卡组画像 `mwg.deck-power/v2`

权威实现位于 `src/game-core/deckPowerProfile.ts`。画像仅使用玩家长期内容和最大属性，不接收当前生命或当前欲望。

### 回合分布

对第 1、2、3、5、8 回合记录中位数和风险分位：

- 生命输出；
- 欲望压力；
- 格挡与其他减伤；
- 治疗；
- 看牌量；
- 能量盈余；
- 死手率。

回合曲线避免把高爆发、持续成长、资源蓄积和慢速控制压缩成同一个平均值。

### 多维得分

当前维度包括爆发、持续输出、生存、资源经济、稳定性、成长、控制、组合、灵活性。每个维度都来自可执行内容分析和模拟分布，不读取展示名称、emoji、世界观或职业文本。

### 标准探针

画像使用六类机械压力探针：稳定持续压力、可预告爆发、后期成长、牌序与控制税、欲望压力、多目标压力。探针只用于程序模拟，不进入世界书，也不会成为 AI 的具体敌人范本。

综合分以风险敏感的探针前沿归一化。五张基础攻击、五张基础防御、80 最大生命的参考构筑约为 100 分。这个锚点用于版本间回归，不代表玩家必须采用该构筑。

### 胜利轴与置信度

生命、欲望和特殊胜利轴分别保留强度与置信度。模拟器无法完整覆盖的动态效果不会被当作零价值；它们进入 `unsupportedFeatures` 并降低置信度。低置信度时，预算变保守，自动校准缩小允许范围。

## 敌人预算 `mwg.enemy-budget/v2`

权威实现位于 `src/game-core/encounterBalance.ts`。预算不是一个孤立总分，而是 AI 可直接使用的数值包：

- 目标分与请求/有效难度；
- 建议有效耐久与持续恢复；
- 第 1、2、3、5、8 回合生命、欲望和格挡压力；
- 单次爆发上限；
- 成长上限；
- 控制预算；
- 目标战斗回合；
- 最少反制窗口；
- 谱系应继承的机械轴；
- 置信度和生成说明。

生命伤害、欲望、控制、格挡、成长与复杂机制共享预算。AI 强化一项时必须收缩其他项，不能把各区间上限同时相加。

## 难度百分比

| 档位 | 设计含义 | 预期体验 |
|---|---|---|
| 10% | 剧情体验 | 宽松容错，快速展示机制 |
| 50% | 轻松 | 多次失误仍可无伤或低损通过 |
| 80% | 标准 | 需要理解主要意图，仍有明显修正空间 |
| 100% | 极限平衡 | 熟练且发挥良好时接近无损边界 |
| 110% | 高压 | 统计上仍可胜，但应消耗生命、欲望、道具或其他局外资源 |

当前生命不是卡组分的一部分，但决定本场可承受上限。资源不足时，`effectiveRatio` 会把请求难度安全封顶；卡组长期分保持不变。

## 程序校准

启用“生成后自动校准”后，程序不再调用模型重写敌人，而是用真实影子模拟寻找数值缩放边界。只允许缩放敌人的生命和可缩放效果数值，并保持：

- 名称、描述、emoji 与身份；
- 行动顺序、概率权重与命中次数；
- 目标选择与触发条件；
- 招牌行动与谱系主题；
- 剧情已经造成的生命比例和活动状态。

校准结果写入 `balance.programCalibration` 作为审计摘要。相同卡组、难度和敌人指纹最多应用一次；小于 2% 的调整不写回，避免加载时反复抖动。

## 性能边界

- 快速静态分始终可用，作为后台画像尚未完成时的回退。
- v2 画像在普通页面渲染后延迟执行，不占用 MVU 写事务。
- 内容解析、画像和影子模拟都使用有界缓存。
- 普通刷新使用 8 个确定性种子；显式离线校准可以提高样本量。
- 指纹只包含机械内容和最大属性，展示文本变化不会使缓存失效。

## 验收不变量

- 改变当前生命或当前欲望，不改变卡组总分；
- 改变最大生命，会改变构筑画像；
- 改名、换描述、换 emoji，不改变评分；
- 难度从 10% 到 110% 时目标分、耐久和压力单调；
- 100% 的参考熟练策略接近无损可胜；
- 110% 保持可胜，且中位资源损失高于 100%；
- 校准不改变命中次数、目标、行动顺序和剧情伤势比例；
- 无法模拟的机制降低置信度，不触发硬拒绝。
