# 通用状态预设与剧情创作边界

AI 可直接使用下列 `sts_` ID，例如 `{apply_status:"sts_strength",stacks:2,to:"self"}`。程序只展开实际引用及其依赖，保存完整定义；自定义状态不会因为效果相近被替换成预设。优先用于小兵和非关键内容。玩家流派、剧情角色与招牌能力应独立创作名称、ID和机制，例如“黑暗仪式”不能自动降格为“力量”。

这些是本项目可执行规则，并非复制尖塔全部角色专属能力。层数、时机、作用域以表格及游戏规则预览为准。敏捷/脆弱沿用本项目通用格挡获取修饰；中毒行动前结算、回合末衰减。需要不同剧情时机可自行登记状态。

| ID | 状态 | 可执行规则 |
| --- | --- | --- |
| `sts_strength` | 力量 | 持续生效，自身造成的伤害增加当前层数（仅攻击伤害）。 |
| `sts_dexterity` | 敏捷 | 持续生效，自身获得的格挡增加当前层数。 |
| `sts_weak` | 虚弱 | 持续生效，自身造成的伤害乘以0.75（仅攻击伤害）；回合结束后减少1层。 |
| `sts_vulnerable` | 易伤 | 持续生效，自身受到的伤害乘以1.5（仅攻击伤害）；回合结束后减少1层。 |
| `sts_frail` | 脆弱 | 持续生效，自身获得的格挡乘以0.75；回合结束后减少1层。 |
| `sts_poison` | 中毒 | 持有者行动前，对自身造成当前层数点伤害，无视格挡；回合结束后减少1层。 |
| `sts_regeneration` | 再生 | 回合结束时，恢复当前层数点生命；回合结束后减少1层。 |
| `sts_metallicize` | 金属化 | 回合结束时，获得当前层数点格挡。 |
| `sts_ritual` | 仪式 | 回合结束时，为自身赋予当前层数层力量。 |
| `sts_thorns` | 荆棘 | 受到攻击伤害包时反击自身层数点伤害，目标为本次攻击者；完全格挡仍触发，反伤不会引发反伤。 |
| `sts_barricade` | 壁垒 | 持续生效，回合开始时保留格挡。 |
| `sts_vigor` | 活力 | 持续生效，自身造成的伤害增加当前层数（仅攻击伤害）；打出攻击牌时，移除自身的活力。 |
| `sts_artifact` | 人工制品 | 每层抵消一次将要赋予或叠加的负面状态，抵消时不执行其赋予或叠加效果。 |
| `sts_intangible` | 无实体 | 每个伤害或生命流失包在格挡前最多造成1点伤害；回合结束后减少1层。 |
| `sts_buffer` | 缓冲 | 每层抵消一次格挡后仍会失去生命的伤害或生命流失包；格挡完全挡住时不消耗。 |

`defense` 是通用状态规则，不依赖预设 ID：`negate_debuff:true` 每层抵消一次减益赋予；`damage_cap:N` 在格挡前限制每个伤害包；`prevent_hp_loss:true` 每层抵消一次格挡后仍会失去生命的伤害包。`retaliate_attack:N|"stacks"` 对攻击来源反伤，完全格挡也触发，反伤不会继续触发反伤。`retaliate_attack:N|"stacks"` 对攻击来源反伤，完全格挡也触发，反伤不会继续触发反伤。无实体和缓冲涵盖生命流失伤害，直接设置生命与处决不是伤害包。
