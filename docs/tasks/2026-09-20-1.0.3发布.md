# 1.0.3 发布记录

用户明确要求发布最新版。本次由已提交源码的隔离工作树完成构建、验证与发布，没有纳入主工作树的无关改动。

## 发布范围

- 角色卡显示名 `魔法少女世界 1.0.3`，内嵌世界书 `魔法少女世界1.0.3`，设计辅助器版本与最低兼容版本均为 `1.0.3`。
- 剧情模式恢复酒馆原生正文、暖色剧情状态栏与新版战斗页；剧情战斗底部继续使用剧情状态栏。
- 手机端战斗、三选一和状态栏统一使用小扑克牌尺寸；爬塔剧情支持展开全文，战后剧情默认生成并保留。
- 修复卡牌空拼写污染与可选欲望效果导致的错误拒绝；停止自动迁移旧模式数据与旧手动扩展安装。
- 完整玩家变更以 `docs/player-release-notes.md` 为准，论坛发布快照为 `docs/forum-update-1.0.3.md`。
