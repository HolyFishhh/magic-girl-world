# 机制补完与验证（2026-09-22）

## 第一阶段：卡牌永久移除和变形权限

卡牌及临时模板的 `lifecycle` 新增两个独立可选布尔字段：`removable:false`（不可永久移除）和 `transformable:false`（不可变形）。省略即允许，`unique` 仍仅限制额外副本。不可移除只保护长期牌组：消耗、遗弃和战斗牌区移除照常；遗忘/打出销毁仍退出本场，但原持有卡战后保留。若还要防止通过变形换掉原卡，须同时设置不可变形。

底层持有卡事务统一拒绝受保护实例的永久移除，覆盖删卡次数、商店、营火及事件；失败不扣次数、金币或修改事务版本。对应选择器过滤不可操作实例；所有牌受保护时不弹空删牌窗。战斗内变形同时在候选与实际提交处检查；永久销毁同时检查战斗实例和原持有实例，避免临时变形绕开原卡限制。

公开卡牌协议、两份 JSON Schema、共享生命周期校验、模板编译/投影、MVU 转换、持有卡序列化、战后恢复、统一词条以及两条中文说明链同步。嵌套字段仍沿用 `lifecycle` 的既有根字段白名单和修复 Schema 来源，无新增旧格式迁移。

回归 `test-card-removal-permissions.mjs` 覆盖公开卡牌及 AST Schema、合法编译/非法值、两条说明、精确实例删除拒绝、事件候选、空候选不提交、真实弃牌与回合清理、临时变形绕过防护、JSON 保存恢复及战后结算；另验证商店拒绝不扣金币/不占服务次数。既有取消回归保持通过。

复查还补齐馈赠批量变形：执行和预览共同跳过不可变形卡。永久删除 API 返回实际结果，战斗日志及动画区分“永久销毁”与“移出本场、原持有牌组保留”。流派/评分风险证据同样区分受保护的遗忘与真正永久丢牌，避免错误报告长期风险。

最终验证：29 组稳定性回归、5 组额外定向检查（批量转化、牌区事务、战外事务、待删卡队列、紧凑 DSL）及应用/扩展双类型检查通过。最后增加的评分证据分支又通过权限契约、评分准确性与应用类型检查。390/1000 像素隔离 Edge 商店检查通过，覆盖受保护牌过滤、取消、确认、缩放及父页面滚动；已查看 390 像素截图，按钮和弹层均在可见区域。该浏览器夹具使用简化卡面，不代表完整玩家实玩验收；没有调用真实模型。
