## 行为与持久化边界

- 完整记录写入本地酒馆当前用户的 `user/files/mwg-evidence-<SHA256>.txt`，使用现有同源、带认证的文件接口。每块上传后重新 HTTP 读取并验证长度和 SHA256，成功后才移除聊天元数据中的内联原文。分块引用还验证整体哈希、记录长度及聊天身份。
- 元数据保留最近记录索引；较早索引保存为不可变分页文件。超过原先 128 条记录仍完整保留，逻辑导出恢复原顺序，不拆掉请求/返回/结果中的某阶段。原实现已经丢弃的记录无法恢复，旧 droppedRecords 计数继续保留。
- 当前安装版的内联证据可在后续正常记录保存或手动重试时转存；读取旧记录本身不会改写玩家聊天。未知版本、损坏索引或跨聊天引用明确报错并保留原数据，不猜测转成空历史。
- 文件名只能由 SHA256 构造，索引不能提供任意网址或路径。读取限制字节数，校验 UTF-8；请求含正文处理均有 15 秒超时。聊天切换/扩展停止使旧异步操作失效；晚到文件不能回写新聊天元数据。
- 网络或校验失败时保留完整内联记录，记录脱敏错误，自动重试间隔至少 30 秒；面板提供手动重试。后台错误不改变生成和战斗结果。

预算：文件块 1 MiB、单归档文件 64 MiB、内存文件缓存 2 MiB；已归档的热索引目标为 64 条/64 KiB。完整聚合导出预算 64 MiB，超限明确提示逐条下载，不下载部分内容冒充完整。**上传失败的内联记录不受热索引预算删除；磁盘总留存没有自动删除上限。** 因此本轮解决正常归档后的聊天体积，不宣称所有异常情况下元数据有硬上限或整个磁盘恒定占用。单条超限保留内联原文和逐条下载入口。

备份或迁移聊天时，必须同时保留该酒馆用户的 `user/files/mwg-evidence-*.txt`；仅复制聊天 JSON 不再包含已归档原文。聊天或失败上传留下的孤立文件不自动删除，避免误删其他引用。玩家存档的玩法数据、规则、世界书和 DSL 未改变；原文保留既有隐私语义，不冒充脱敏日志。
