## 修复

- **MVU 保存回读误报**：清除可选字段留下 `undefined`，角色卡 JSON 克隆读取会省略该字段。现在在同一 JSON 表示上合并、写入和验证，覆盖嵌套数组；实际写入丢失、并发冲突、旧版本及聊天/消息/swipe 切换仍拒绝。不重放 updater，不增加写入重试。
- **欲望成长漏校验**：批量、单节点、未报告错误收集和战斗反馈复验均补上成长检查，和敌人/奖励问题一起进入既有一次有限修复。无玩家效果不允许创造成长；合法成长入战仅暂存、胜利才应用，败退不应用。玩家点击已保存的非法 ready 节点时进入既有重新排队路径，不提前进入战斗或改写构筑。
- **等价 JSON 误判**：重复结果及共享成长状态的对象字段顺序不影响内容相等判断；数组顺序、实际规则和身份冲突仍拒绝。
- **生成上下文**：节点生成与修复明确提供玩家 `player_lust_effect`；Prompt、世界书区分玩家/敌人，缺失、null、空模板不创造成长。
