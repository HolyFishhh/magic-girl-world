# 2026-09-23 预设状态目录与剧情创作范围

## 用户要求与处理

世界书完整列出 15 项预设状态，同时明确仅在低质量敌人和偏中立卡牌中使用；剧情相关敌人、复杂敌人、玩家自己的卡组必须根据剧情设定具体生成。

本轮修改：

- 通用 DSL 世界书保留唯一的 15 项目录，补齐增益/减益分类（11 项增益、4 项减益），每项包含精确 ID、中文名和可执行规则；活力文案明确为攻击牌结算后清除。
- 新增共享 `builtinStatusUsageContract()`，将“优先/主要用于小兵”改为“仅用于低质量敌人或偏中立卡牌”。低质量敌人明确指无剧情身份、机制简单的普通杂兵，不是允许敷衍、不完整规则，也不能仅因数值/稀有度低或位于普通战斗节点就套预设。
- 剧情相关敌人、复杂敌人及为玩家生成的整套卡组（含开局与后续专属卡牌），必须依据剧情设定、身份、能力来源与当前构筑创作名称、独立 ID、触发条件和可执行效果；不得直接套这 15 项预设，不得仅改名字或堆通用 buff 代替剧情设计。
- 七份世界书使用同一规则：通用 DSL、遇敌生成、首条初始化、普通变量更新、初始内容修复、场景修复、永久内容规范。通过共享引用契约同步生成/修复 Prompt 与战斗节点 Schema 描述，避免世界书和后台提示不一致。
- **仅改变创作指令，不增加质量硬门槛**。没有改变预设的执行逻辑、Schema 字段、编译合法性、存档或两条中文效果渲染代码。结构修复仍保留合法内容，不能据此拒绝、删除或改写既有卡牌、敌人或玩家存档。
