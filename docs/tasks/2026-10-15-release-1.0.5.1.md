# 1.0.5.1：诊断修复与 AI 创作边界纠正

## 范围与依据

在隔离工作树 `tmp/fix-mvu-desire-20261015`、分支 `codex/release-1.0.5.1` 上接续 5217f1c；原工作树和玩家存档不作为源码修改对象。用户授权修复后发布 1.0.5.1。私有诊断导出仅本地读取，不提交原文、玩家内容或凭证。

诊断中的明确问题：Helper 接口缺失；模型把节点请求误解成 Schema 文档问答；外层批次有效但部分成员缺少 based_on_revision；一个效果对象含冲突的重复 to，后续修复为空。开局“无法提取固定错误槽”缺少对应原稿，无法据该导出确认根因，不宣称已复现或修复。

## 实现

- Helper 通过每次调用动态读取全局实例，支持晚加载/重载；明确注入的测试实例及 null 保持隔离，不新增轮询或无限重试。
- DeepSeek 完整节点 Schema 参考先于任务，末尾根摘要明确要求执行前文生成任务；保留完整字段、原渠道设置及既有一次有限恢复预算。
- 批次外层身份和 revision 核验后，成员只继承缺失的 based_on_revision。明确冲突版本、错误 request_id/node_id/kind、缺漏成员仍拒绝；不按数组位置猜身份。
- 撤销欲望收益/胜利路径、已有欲望效果、描述文字启发式一致性等内容门槛。允许 AI 明确新增或深化欲望效果；程序不生成默认欲望效果，不衡量成长曲线。
- 移除敌人数值自动缩放和强度反馈追加生成；评分/模拟仅用于建议与审计。移除预定人数、固定奖励数量/稀有度、固定三项馈赠等验收限制，合法候选完整保留；商店记忆卡只增加其自身购买名额，不覆盖 AI 已写名额。
- 保留运行协议、字段类型、操作/公式、引用闭合、ID 冲突、唯一性、结构复杂度与事务隔离等执行边界。冲突重复键不能静默选一个目标，仍交有限修复；程序拥有的路线、货币、价格和库存规则不改变。
- Prompt/世界书/Schema/修复指引与运行链同步；删除无效的 missing_lust_effect 修复槽。版本及安装说明统一为 1.0.5.1，扩展包允许四段数字版本。

## 验证

已通过专项：内容契约与初始可玩性、奖励保留、欲望新增/强弱自由、节点批次 revision、Helper 晚加载和实例替换、完整 Schema 传输、开局与节点控制器、一次有限修复、节点激活与胜败结算。成长经过 JSON 保存恢复，入战不提前赋予、只在胜利生效。

完整机制门禁（含 44 组稳定性）、发布构建门禁（共享世界书同步后从该检查接续）及扩展包测试通过。常规导入检查原先要求切换当前角色，与隔离安装要求冲突，已去除此断言；独立快照明确核验当前角色不变。不把离线回归当作真实渠道模型或 iOS 实机验收；本轮没有自动刷新用户页面、调用真实模型或推进聊天。
