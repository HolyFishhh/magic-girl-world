## 状态操作阶段

新增 `status_action`，支持按类别、稳定 ID、定义标签和最低层数筛选，从当前精确执行者或对方选择若干/全部状态，移除、复制或转移完整/部分层数。手选可取消，敌人自动选择。转移只扣除实际接收层数，目标满层或被人工制品阻挡时保留来源；状态 ID/名称保留，已有期限合并取较长值、无期限优先，仍遵循原定义衰减。召唤的 self 是召唤实例，不能冒充主人。

共享校验和两份 JSON Schema、公开生成协议、状态 tags 字段及投影、有限修复白名单、宿主执行、状态生命周期、两条中文说明、通用选择窗口取消入口同步。轻量纯效果执行器对该操作输出宿主命令，完整语义由正式状态宿主执行，不能将轻量投影当成真实状态转移试打。

`test-status-action-contract.mjs` 验证公开/编译 Schema、正式命令宿主与玩家/敌人/召唤状态生命周期、上限/阻挡/部分转移、剧情名称、期限、JSON 保存恢复、精确选择、非法/取消输入、出牌事务取消后恢复资源与手牌，以及有限修复保留标签/过滤器/锁定兄弟项。既有状态生命周期、效果命令宿主、召唤防御端到端回归通过。新测试纳入稳定性集；全量检查和浏览器验收在最终阶段完成。
