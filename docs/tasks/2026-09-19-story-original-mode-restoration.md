# 剧情模式原布局恢复

用户反馈爬塔模式更新后，剧情模式原有内容全部不可见。调查确认世界书、剧情开场、NPC、势力、衣物与背包数据并未删除；问题来自公共页面被新的爬塔统一状态栏接管，旧 `.statusbar-panels` 被全局样式隐藏，剧情页面还会处理残留的爬塔状态。

## 本轮修复

- common + story 恢复原剧情正文、状态栏、人物关系、势力关系、卡牌资源和自由行动布局；只有 tower 才创建统一状态栏并搬移地图、节点和奖励。
- 剧情正文忽略 `run_node`、`completed_expedition`、`mwg_tower_initial_commit` 和战后剧情缓存；剧情模式不消费路线事务，也不唤醒待生成的幕间开场。
- 原卡牌资源面板继续使用当前结构化卡牌与规则说明，并补充能力、当前战斗状态及层数、资源、我方欲望效果、当前姿态和召唤成长。
- 现有剧情字段和存档只读保留，不重建、不迁移、不推进玩家存档。设计辅助器的剧情 MVU 上下文、有限修复和持久写回路由经检查无需修改。
