# MVU 额外模型配置

`0.5.116` 起，角色卡直接使用 MVU 自带的“使用内置破限”。角色脚本不会创建、读取、切换或覆盖任何 SillyTavern preset，也不需要额外导入 preset 文件。

导入并选择最新角色卡 `魔法少女世界 0.5.139` 后，卡内加载器会在该版本首次加载时设置：

- 更新方式：额外模型解析
- 破限方案：使用内置破限
- 自动请求：开启
- 模型来源：与插头相同
- 请求方式：依次请求，失败后重试
- 请求次数：2
- 最近聊天：2 层
- 最大回复：20000 token
- 应答格式：聊天消息
- 兼容假流式：开启
- thinking：默认关闭；Gemini 随机头部默认关闭
- 世界书白名单：只读取 `[mvu_update]` 条目

主模型只负责剧情正文和协议标记，不输出变量命令；MVU 额外模型读取完成后的剧情，再输出唯一的 `<UpdateVariable>`。普通轮只注入轻量更新规则；首轮初始化、明确遇敌、奖励或修复时才临时注入完整内容规范。

角色卡不保存 API Key。若需要让 MVU 使用独立模型，可在酒馆助手的 MVU 设置中手动修改；卡内默认只在新的角色卡版本首次加载时写入，不会在每次消息中反复覆盖玩家之后的设置。

角色运行时会在酒馆顶部提供与聊天楼层无关的设置悬浮球；点击后只展开通用设置。MVU 二阶段拥有另一张独立状态窗，默认在第二轮开始时自动展开，非流式生成期间只显示“正在生成变量”和旋转指示，模型返回后继续显示写入状态。成功后，完整变量变化由对应消息楼层中的独立 HTML 展示；顶部状态窗不再重复拼接摘要。只有模型/酒馆实际返回 reasoning 且用户以后显式开启时才显示思考文本，不伪造思考内容。
