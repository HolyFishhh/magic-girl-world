# 敌人生成与全屏入口验收（0.5.145）

## 改动

- 战斗页按钮明确显示“全屏游玩”，进入后显示“退出全屏”；按钮标题说明其会占满当前窗口并可返回酒馆楼层。
- 小屏布局不再隐藏全屏按钮文字。
- 敌人机制由本轮剧情中的身份、形态、行为与场景决定，不再把欲望主题固定为纯欲望流，也不预设欲望与生命伤害的比例。
- 普通敌人可在剧情需要时使用少量自定义状态、特色能力、临时牌或牌库干扰；简单敌人仍可保持简洁。
- 所有敌人必须保留可执行终局路径和合理应对窗口；叙事说明不能代替实际机制，所有新状态仍需完整注册。
- 移除初始牌组总 `quantity` 不得超过 13 的运行时错误和重复初始化条件。合法卡组可自由超过 13；仍保留字段形状、费用、效果可执行性、状态注册、重复 ID、基础可打出性与胜利路径校验。
