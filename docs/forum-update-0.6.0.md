#### beta0.3.0（角色卡 0.6.0）

- 正式开放三幕爬塔模式，新存档可以选择剧情模式或爬塔模式，开始后不可中途切换。
- 新增随机路线地图、开局馈赠、普通敌人、精英、事件、篝火、宝箱、商店、首领与作者鱼结局。
- 爬塔过程改为单页连续游玩，并在玩家处理当前节点时提前准备可达路线的后续内容和战斗奖励。
- 新增卡组评分、敌人评分、10% 到 110% 难度、回合能力模拟、敌人数值校准、流派总览、演变方向与敌人谱系记忆。
- 完善多敌人战斗，多个敌人会同时显示生命与行动意图，并支持直接选择攻击目标。
- 三幕会逐步提高强度，通关后统计击败敌人总分和平均相对难度，并用总分攻击正在改代码的作者鱼。
- 设置悬浮窗现在可以查看扩展版本、卡组强度、流派、后台生成状态和故障恢复入口。
- 完善手机端开始页、战斗、奖励、地图、全屏与终局显示，并支持刷新或重启后的路线和战斗恢复。
- 修复常驻牌库稀有度外观、致命牌战报、扩展缺失提示、慢模型超时和长期操作界面累积等问题。

剧情模式只需导入角色卡即可游玩。爬塔模式需要额外安装 `0.2.0` 或更高版本的“魔法少女世界设计辅助器”，角色卡悬浮窗会在扩展缺失时显示下载和安装说明。
