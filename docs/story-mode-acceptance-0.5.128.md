## 本轮修复对应的验收点

- MVU 完成态不会被迟到事件回退成“正在应用变量”；非流式请求显示明确加载状态。
- 卡内父窗口只保留一个运行时，事件、轮询器、战斗协调器和动画队列可销毁，避免对话越长监听器越多。
- 玩家与敌方修饰符以显式目标计算和展示；卡牌、奖励、普通状态栏和战斗详情共享同一中文效果解析器。
- 卡牌能力记录来源；敌人行动支持向玩家本场手牌或牌堆插入临时卡牌；失败惩罚只走失败事务。
- 战斗结束交接固定包含玩家完整状态、敌方状态和具体战斗日志，不再由普通状态栏额外收集“自定义行动”。
