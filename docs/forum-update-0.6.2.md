# 魔法少女世界 beta0.3.2

对应角色卡：`0.6.2`
对应爬塔扩展：`0.2.2`

- 开场改为独立的剧情模式与爬塔模式入口，选择后模式固定，剧情玩法不受爬塔规则影响。
- 爬塔首轮会自然进入连续战斗处境，并在同一页面直接显示馈赠、地图和三条主路线。
- 三幕地图统一为“唯一馈赠起点—最多五列分支与汇流—唯一首领终点”，普通节点最多二分叉。
- 当前可达的 1 至 3 个节点会一次批量准备，减少逐节点等待；路线改变后会自动丢弃无效分支。
- 新增爬塔专属角色面板，可查看生命、欲望、成长、卡组、遗物、道具与能力；手机端更紧凑。
- 爬塔道具最多携带三个，普通与精英战改为概率掉落，增加路线与资源取舍。
- 优化节点正文格式，修复同层重开新塔时可能沿用旧节点缓存的问题。

请导入显示名为 `魔法少女世界 0.6.2` 的新角色卡，并安装 `0.2.2` 或更高版本的“魔法少女世界设计辅助器”。
