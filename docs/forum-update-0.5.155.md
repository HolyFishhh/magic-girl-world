# 魔法少女世界 0.5.155 更新记录

对应玩家版本：`beta0.2.1`

- 新增可选的游戏设计辅助器。它只服务于本角色卡的第二轮变量生成，会结合当前卡组、成长与剧情遭遇给出更合适的敌人强度，不影响普通剧情和其他角色卡。
- 新增卡组多维评分与可视化总览，可从输出、生存、资源、稳定性、成长、控制、联动、灵活性和卡组质量等方向观察当前构筑；难以打出、效率过低或偏离构筑的卡牌会真实拖累评分。
- 新增 10% 至 110% 的敌人难度调节和自动平衡。低难度提供更高容错，高难度会逐步压缩无伤空间，同时保留可通关边界，并尊重剧情已经造成的伤势与状态。
- 新增流派总览、相邻演变和桥接卡建议。奖励可以围绕现有流派继续强化、自然转向邻近玩法，也会保留不绑定流派但普遍实用的散卡，减少构筑越来越单一的问题。
- 新增敌人谱系记忆。同族、精英与首领可以继承有辨识度的能力或行动，同时结合剧情发展出更强的变化，连续遭遇更有连贯感。
- 扩展通用卡牌机制，可改变手牌中选中、随机、最左或最右卡牌的伤害、格挡、欲望与状态层数，并支持回响式重复打出、前若干张牌免费、卡牌附着和持续升级等玩法。
- 新增自定义战斗资源、召唤物、姿态与形态、法球、延迟效果、阈值触发和多敌人战斗，可组合出召唤流、资源流、姿态流、法球流、回响流、零费流、附着流和处决流等更多构筑。
- 丰富敌人设计。敌人可使用条件行动、阶段变化、被动能力、召唤、控制、减益、牌库干扰与多目标配合；欲望型敌人也会保留能够推动战斗结束的伤害或叙事手段。
- 设计辅助器的设置、难度、卡组评分、流派分布和敌人预算统一收进角色卡悬浮设置窗；没有安装对应组件时相关内容会自动隐藏，不占用酒馆扩展管理栏。
- 变量生成窗口现在可以查看第二轮生成的完整过程与结果，并可直接输入自然语言修复要求，让 AI 按玩家描述调整错误的卡牌或战斗内容。
- 恢复随等级成长获得删卡次数的机制，并完善领取、升级、移除、永久强化与跨战斗继承，使长期构筑能够持续整理和成长。
- 首次开局改为以“牌库是否真实为空”判断初始化。无论使用开始页还是直接自由输入都能正常生成初始牌组；生成中断时只补齐缺失内容，不会重复重置已有卡牌。
- 优化敌人意图显示。头像旁会用简洁图标预告下一轮行动，外部只保留行动名称，点击后再查看完整效果，多个行动与状态不再互相挤压。
- 继续优化桌面高分辨率与手机端战斗布局，调整顶部牌堆、弃牌堆、全屏入口和手牌区域的空间分配，减少空白、重叠、横向滚动与详情显示不全。
- 修复大量组合玩法与长期游玩问题，包括低质量卡错误抬高卡组强度、诅咒未进入抽牌模拟、敌我目标混淆、初始牌组丢失、删卡成长丢失，以及复杂效果在战斗、奖励和详情页面显示不一致等问题。

导入新版本时，请选择显示名为 `魔法少女世界 0.5.155` 的角色，并确认导入内嵌世界书。为避免 SillyTavern 继续使用旧角色、旧世界书或旧脚本缓存，不建议直接覆盖同名旧卡。

完整历史见 `docs/player-release-notes.md`。
