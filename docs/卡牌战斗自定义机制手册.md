# 卡牌战斗自定义机制手册

更新时间：2026-08-29  
适用范围：剧情模式战斗系统  
状态标记：除“当前边界”明确列出的项目外，本文描述的机制均已由通用数据契约和运行时实现，不依赖识别某张固定卡牌、某个固定状态或某类题材。

## 怎么读这份手册

- **已实现**：可以直接由卡牌、状态、能力、遗物、道具、敌人行动或召唤物使用。
- **组合可实现**：没有单独写死的专用机制，但可以由多个通用效果可靠组合出来。
- **当前边界**：本版本不支持或刻意限制的能力。
- 卡面上的**中文描述**负责题材、动作和非数值表现；效果标签负责如实展示真正执行的规则。两者不互相替代。
- 战斗数值内部保留两位小数，卡面与舞台最多显示一位小数；生命、格挡、层数和资源等有各自的合法上下限。

## 一、内容对象

### 卡牌类型

| 类型 | 定位 | 默认行为 |
| --- | --- | --- |
| Attack | 攻击牌 | 适合直接伤害、连击、斩杀、攻击触发联动 |
| Skill | 技能牌 | 适合格挡、恢复、资源、状态和牌区操作 |
| Power | 能力牌 | 适合注册持续能力或改变本场战斗规则；打出后自动消耗 |
| Event | 事件牌 | 用于结束或转入叙事事件；唯一主效果是叙事终止 |
| Curse | 诅咒牌 | 无费用栏，可留在手中、被弃、被消耗或按条件反噬 |

### 稀有度

`Common / Uncommon / Rare / Epic / Legendary / Corrupt` 均有独立的卡面表现。稀有度表达规则影响力和构筑潜力，而不只是颜色：基础构件可以是 Common，改变构筑方向的核心通常是 Rare 以上，Corrupt 表示带代价的危险力量或诅咒。

### 其他战斗内容

- **遗物**：通过触发器或被动修饰长期影响战斗。
- **道具**：有使用次数，主动执行一次效果。
- **能力**：拥有来源、触发时机与效果，可来自卡牌、状态、遗物、敌人或其他战斗内容。
- **状态**：全部自定义；系统不依赖“中毒”“易伤”等内置名称。
- **敌人行动**：可有多个行动、权重、顺序模式、条件与目标规则。
- **敌人被动**：一个敌人可拥有多个独立被动，界面逐项显示，等价于敌方遗物。
- **召唤物**：独立拥有生命、格挡、状态、资源、行动、能力和死亡流程。

## 二、卡牌基础字段与关键词

### 费用

- 固定能量费用：非负整数。
- X 费：以当前实际使用能量或指定资源计算；界面用“使用能量”表达。
- 复合费用：一张牌可同时消耗能量和多个已注册的自定义资源。
- 所有费用组件原子支付；任一组件不足时不会发生部分扣除。
- Replay 额外结算不会重复付费。
- 真正免费、费用被改成零、只免除某一种资源是三种不同规则。

### 卡牌关键词

| 关键词 | 实际作用 |
| --- | --- |
| 固有 Innate | 开局优先进入手牌 |
| 保留 Retain | 回合结束时不因普通清理被弃掉 |
| 消耗 Exhaust | 结算后进入消耗区 |
| 空灵 Ethereal | 回合结束仍在手中时优先进入消耗区 |
| Replay | 一次出牌产生额外的完整结算，不增加卡牌自身 hits |

这些关键词都可以被卡牌补丁或附着在战斗中临时、整局或永久增加与移除。

## 三、基础效果

以下效果均为**已实现**，并能按顺序组合：

- 造成伤害、治疗、获得格挡、获得或失去能量、增加或降低欲望。
- 设置生命等战斗属性到指定值。
- 多段命中；命中次数与每段数值分开处理。
- 抽牌、预见、检索、弃牌、消耗、回收。
- 施加、叠加、移除自定义状态。
- 获得、设置自定义战斗资源。
- 直接处决、按生命阈值处决、明确终止战斗。
- 生成卡牌、保证某类卡至少存在若干张、复制、变形、移除、升级。
- 延迟到未来回合或未来阶段执行。
- 进入姿态、充能或激发 Orb、增加额外回合、强制结束回合。
- 召唤单位、生成正式敌方增援。

普通攻击伤害、效果伤害、直接生命流失、反伤、持续伤害与处决拥有不同的事件来源，可被触发器准确区分。

## 四、公式与条件

### 可读取的常用数据

- 双方生命、生命上限、欲望、欲望上限、能量、格挡。
- 双方任意已注册状态的层数。
- 手牌、抽牌堆、弃牌堆和消耗堆数量。
- 本次实际使用的能量或自定义资源。
- 当前回合、当前回合总出牌数及各类型出牌数。
- 最近一次伤害、实际生命流失、治疗、资源消耗和历史事件计数。
- Orb 当前内部数值、状态当前层数等特定上下文数据。

### 允许的计算

- 加、减、乘、除和括号。
- 大小比较、相等判断、与、或、非。
- 条件二选一。
- 安全的取整、最小值与最大值等受限数值原语。

### 条件效果

每个效果步骤都可以带条件。条件只决定该步骤是否执行，不依赖中文描述猜测。由此可组合实现：

- 手牌为空时增强。
- 上一张牌属于某类型时追加效果。
- 目标状态达到阈值时引爆或处决。
- 本回合第一次、第三次或每若干次事件触发。
- 敌人准备攻击时获得不同收益。
- 实际受到生命伤害后按损失量反击或恢复。

非法公式、除零和不存在的字段会在战斗开始前被拒绝，不会执行一半后留下脏状态。

## 五、自定义状态与持续修饰

### 状态没有固定题材

状态必须手动注册名称、图标、说明、类型、层数规则和实际效果。可以复用通用效果，但不存在按状态名字自动附送的内部定义。

### 状态触发阶段

- 获得时。
- 再次叠加时。
- 回合变化时。
- 消失时。
- 持有期间持续生效。

### 层数

- 可设层数上限。
- 回合变化可保持、固定增加或减少，也可按比例变化。
- 层数不会低于合法下限。
- 状态效果中的公式可以读取自己的层数。

### 持续修饰

持有期间可以对下列通道进行加、减、乘、除或设置：

- 造成的伤害与受到的伤害。
- 造成的欲望与受到的欲望。
- 治疗与格挡获取。

修饰符按统一顺序结算并在界面展示来源，敌我修饰不会混用。

## 六、触发器与历史事件

### 常用触发时机

开战、回合开始、回合结束、打出任意牌、打出攻击/技能/能力牌、抽牌、弃牌、消耗、洗牌、受到或造成伤害、受到或造成治疗、欲望变化、获得或失去增益/减益、获得或失去格挡、单位被击杀等均可触发。

### 精确筛选

触发器可以继续限制：

- 本回合、本场战斗、整局、单卡实例或同阵营范围。
- 第一次、第 N 次、每 N 次。
- 事件阶段、弃牌原因、伤害类型。
- 卡牌类型、卡牌模板、实际卡牌实例。
- 来源种类、来源 ID、行动者和目标 ID。

触发器带递归保护与事务回滚。某个触发失败时不会把费用、牌区和已执行一半的数值留在战斗中。

## 七、牌区与统一选择器

### 可选牌区

- 手牌。
- 抽牌堆。
- 弃牌堆。
- 消耗堆。
- 手牌、抽牌堆和弃牌堆的合集。
- 包含消耗堆在内的四区合集。

### 选择方式

- 随机、手动选择、最左、最右、顶部、底部、全部。
- 前 N 张、后 N 张或指定数量。
- 无合法目标时安全完成；手选取消时不产生部分修改。

### 过滤条件

- 卡牌名称、类型、稀有度、固定费用或费用范围、标签、来源、升级状态。
- 同模板、整局牌组实例、当前战斗实例。
- 只选择根实例，排除临时复制品。

### 牌区操作

- 预见：查看抽牌堆顶部并选择放弃，不触发普通抽牌和弃牌触发。
- 检索：从抽牌堆选择原卡进入手牌，不触发普通抽牌触发。
- 弃牌：保留准确原因，支持主动选择和随机弃牌。
- 消耗与回收：可在弃牌堆与消耗堆间处理实际卡牌实例。
- 移到抽牌堆顶部或底部，并保持确定顺序。
- 从非手牌区域自动打出，完整执行卡牌与触发器。
- 改变正在结算卡牌的最终去向。

## 八、修改卡牌

### 直接修改可执行数值

可以选择手牌中随机、最左、最右、手选或满足过滤条件的卡牌，对以下数值加、减、乘、除：

- 伤害。
- 格挡。
- 欲望。
- 施加状态的层数。

修改会作用于对应数值通道，但不会增加 `hits`、改变卡牌类型或偷偷改变目标。

### 通用卡牌补丁

补丁可以修改伤害、格挡、欲望、层数、费用、Replay 和卡牌关键词。作用域包括：

- 仅本次结算。
- 本回合。
- 直到该牌打出。
- 本场战斗。
- 整局成长。
- 永久成长。

补丁可以只影响当前战斗实例、整局实例、同模板卡、满足过滤条件的卡，也可以显式影响未来副本。

### Enchantment 与 Affliction

- Enchantment 是一组有名称、来源和统一生命周期的正面附着。
- Affliction 是敌人或风险机制施加的负面附着。
- 附着可同时包含数值、费用、关键词、Replay、X 值、动态费用、出牌许可和弃牌自动打出等变化。
- 同一张牌最多一个 Enchantment，但可有多个不同 Affliction。
- 附着按打出、弃牌、回合结束、战斗结束、整局结束或手动移除统一解除。

## 九、生成、复制、变形、升级与成长

- **生成**：把完整卡牌模板加入手牌或抽牌堆；战斗临时卡不污染长期牌组。
- **确保存在**：扫描四个战斗牌区，只补足缺少的根实例，避免每次触发重复生成。
- **复制**：明确继承升级、补丁和附着的范围，不会误改原卡。
- **变形**：保留稳定实例身份和合法继承关系，再替换为新模板。
- **升级**：支持本场、整局和永久升级，也支持多级升级。
- **成长**：击杀、打出或满足条件后，可以让特定实例、同模板或整个过滤组永久成长。
- **移除**：可从当前战斗删除，也可通过整局事务永久删卡。

## 十、弃牌、诅咒与自动打出

- 弃牌原因会区分玩家选择、随机效果、普通效果、回合清理、预见、回收、消耗、生成、复制、变形和自动打出。
- 卡牌可以拥有“被特定原因弃掉后”的独立效果；卡面会明确写“被弃掉后获得……”而不是显示模糊条件。
- Sly 类规则可以让牌在合法弃牌原因、正确回合阶段下免费自动打出。
- 自动打出失败时可以明确回到弃牌堆、消耗堆、抽牌堆顶部/底部、手牌或移出战斗。
- 敌人行动和被动可以向玩家手牌或抽牌堆插入临时妨碍牌、状态牌或诅咒牌。
- 空灵、保留、诅咒留手和系统清理拥有稳定优先级，不依赖 DOM 顺序。

## 十一、Replay、免费牌与规则替换

### Replay

- 每回合前 N 张牌额外完整结算若干次。
- 所有符合过滤条件的牌都可额外结算。
- 单张卡也可携带独立 Replay。
- 多个 Replay 来源可以叠加。
- 费用只支付一次；每次 Replay 产生完整事件，但有递归保护。

### 免费牌

- 每回合前 N 张牌免除全部费用。
- 可以只免能量或只免某种自定义资源。
- 免费 X 费组件按使用零资源计算，不伪造已支付值。

### 其他持续规则

- 回合结束保留全部手牌。
- 回合切换保留格挡。
- 限制抽牌、格挡获取、能量获取或特定卡牌出牌次数。
- 禁止或重新允许特定类型、费用、标签或实例的卡牌。
- 把满足条件的牌统一送往弃牌、消耗、抽牌堆、手牌或移除区。

## 十二、自定义资源与多资源费用

- 玩家、敌人和召唤物都可以注册自己的战斗资源。
- 每项资源有名称、图标、当前值、上限和回合刷新方式。
- 刷新方式为每回合重置或跨回合保留。
- 卡牌可以消耗一个或多个资源，也可以同时包含多个 X 费组件。
- 公式可以分别读取每种资源的实际使用量。
- 没有注册的资源不会被效果临时捏造。

## 十三、姿态、Orb 与回合控制

### 姿态

- 同一实体只保留一个互斥姿态。
- 切换时执行旧姿态退出和新姿态进入效果。
- 姿态可以提供持续修饰与出牌规则。
- 重复进入同一姿态不会重复触发入场效果。

### Orb

- 每个 Orb 有独立身份、图标、内部数值、被动效果和激发效果。
- Orb 按槽位从左到右排列。
- 槽位满时，新 Orb 会先挤出并激发最左侧 Orb。
- 可主动激发第一个、最后一个、指定类型或全部 Orb。
- 可增减槽位，也可修改 Orb 内部数值。

### 回合控制

- 玩家或敌人可以获得额外完整回合。
- 可以强制结束当前一方回合。
- 多敌行动队列、预约效果和存档恢复会保留确定顺序。
- 战斗终态优先，胜负已定后不会继续消费额外回合。

## 十四、多敌系统

### 敌人实体

- 每个敌人拥有独立 ID、生命、格挡、欲望、状态、资源、姿态、Orb、行动、被动和欲望效果。
- 玩家可以选中活动目标；目标死亡后自动切换到仍存活的前排实体。
- 所有敌人离场后才判定胜利。

### 目标模式

- 当前目标。
- 指定 ID。
- 全体敌人。
- 随机一个或随机多个。
- 最低生命比例或最高生命比例。
- 多段攻击可以锁定一组目标，也可以每段重新选择仍存活目标。
- 随机多段可以允许或禁止重复命中同一敌人。

### 行动顺序

先比较行动优先级，再比较速度，最后保持敌人数组中的稳定顺序。行动前已经死亡的敌人会被跳过；玩家进入终态后，后续敌人不再行动。

### 增援、分裂与复活

- 在场敌人的行动、状态或被动可生成新的正式敌人。
- 新敌人拥有自己的行动和被动，参与目标选择与胜负判定。
- `defeated` 在敌人移除前触发，因此可以恢复生命、分裂、变形或召来增援。
- 同时存活敌人上限为 12，整场累计上限为 64，防止无界递归。

## 十五、召唤物系统

### 基础能力

- 召唤物拥有独立实例 ID、格挡、状态、资源和修饰符；可以是有生命单位，也可以是不承受伤害的无生命常驻物。
- 可拥有一个旧式行动或多个带权重的行动。
- 可拥有多个各自独立的触发能力。
- 行动和能力中的 `self` 精确绑定该召唤实例，不会误作用主人或全部同阵营召唤物。
- 需要作用主人时使用显式的“召唤者效果”嵌套程序；该程序内的自身才表示召唤者，可为主人提供格挡、能量、状态和其他普通战斗效果。
- 可以治疗、伤害、强化、改变行动次数、速度、优先级和资源。
- 可以立即命令指定召唤物行动。
- 可以用最左、最右、随机、随机多个、全部或手动选择召唤物；伤害、治疗、强化、资源、状态、立即行动、移除和复制共用这一套选择器。
- 可以复制召唤物当前完整状态，包括生命、资源、状态、强化后的行动与触发能力。
- 可以统一强化召唤物行动和离场能力的伤害、格挡、欲望或状态层数；标为“固定效果”的经济能力不会被放大。

### 顺序与展示

- 先按行动优先级，再按速度、创建顺序和同单位行动序号结算。
- 舞台上召唤物以 emoji 环绕主人排列，点击可查看生命、格挡、资源、状态、全部行动和全部能力。
- 召唤物行动动画从自己的 emoji 发出，不借用主人的头像。

### 容量与替换

- 每个阵营基础召唤容量为 3，可由 Buff、能力或遗物继续增加，不设固定总硬上限。
- 超过当前容量时，创建最早的存活召唤物默认会被新单位挤掉。
- 被挤掉的单位按**被击杀**处理，完整触发自己的 `defeated` 能力并写入战斗日志。
- 也可显式选择拒绝生成或替换当前生命比例最低的单位。

### 拦截

- 有生命召唤物默认援护主人并拦截主人格挡后剩余的普通单体攻击伤害，最早召唤者优先。
- 先消耗召唤物自己的格挡，再扣召唤物生命，剩余伤害才回到主人。
- 可限制每回合拦截次数，并以优先级、速度和创建顺序决定谁先拦截。
- 直接生命流失和非攻击效果不会被误拦截。
- 无生命召唤物不显示生命、不受伤、不治疗，也不会援护主人。
- 无生命单位仍可行动、持有资源和状态、触发能力、被选择、复制、强化或移除，因此可以表达持有、主动激发与离场结算的有序容器。
- 为主人增加资源的部分使用召唤者效果；不应随召唤强化变化的固定经济数值标记为固定效果。

### 唯一伙伴槽

需要唯一伙伴时可使用槽位：再次召唤可以强化或替换当前伙伴；伙伴倒下后可以生成新实例、原样复活或强化复活。普通召唤军团不使用唯一槽位。

## 十六、敌方行动、被动与意图

- 敌人可以有多个行动，使用随机、概率、顺序或“先顺序后概率”模式。
- 行动可以组合伤害、欲望、状态、格挡、资源、牌库污染、召唤和增援等任意已实现效果。
- 敌方下轮行动的实际效果显示在中央战斗舞台敌人上方，并可展开查看详情。
- 敌人可以拥有多个独立被动，例如首次受击获得格挡、受到特定伤害后反击、死亡时分裂等。
- 被动有自己的名称、来源、描述、触发器和效果，不会塞成一段不可验证的文字。

## 十七、欲望满溢终极效果

双方欲望效果都是高门槛的终极能力，必须足以逆转或决定胜负，不能只等价于一张普通卡或一次普通行动。

可用方向包括：

- 高额终结伤害或阈值处决。
- 强力且立即影响战局的增益或减益。
- 召唤强力单位或正式增援。
- 获得额外回合、资源爆发或大量牌序优势。
- 以可执行的击杀、处决或战斗终止落实叙事终局。

欲望题材敌人不必是纯欲望数值流。敌人仍应根据剧情组合生命伤害、控制、状态、召唤、牌库干扰和欲望压力，并保留能够真正结束战斗的路径。

## 十八、延迟、预约与原子事务

- 效果可预约到回合开始、抽牌前、抽牌后或回合结束。
- 可等待若干回合，也可按固定间隔重复有限次数。
- 延迟爆发、延迟处决、未来牌区操作和状态倒计时都能保存来源与顺序。
- 额外回合、跳过阶段或存档恢复不会让预约效果丢失或重复执行。
- 卡牌出牌、费用支付、牌区移动、选择、效果、触发器和日志属于一个事务；失败时整体回滚。

## 十九、体系化构筑示例

以下是**组合可实现**的机制骨架。题材、名称、状态和视觉都可以随剧情替换，不构成世界书固定示例。

### 1. 基础攻防循环

低费攻击负责稳定输出，技能牌提供格挡与少量抽牌，能力牌在使用攻击后补充防御。覆盖基础伤害、格挡、抽牌和触发能力。

### 2. 状态叠层与引爆

多张牌向目标叠加自定义层数，另一张牌按层数动态伤害并移除状态；状态达到阈值时也可以自动引爆或处决。

### 3. 弃牌循环

主动选择或随机弃牌换取抽牌、资源与防御；被弃牌拥有独立弃牌效果，部分附着牌在合法弃牌时自动免费打出。

### 4. 消耗与回收

强牌打出后进入消耗堆，其他牌从消耗堆选择回收、复制或把牌放回抽牌堆顶部，形成有限资源循环。

### 5. X 费资源爆发

牌消耗全部能量或自定义资源，按实际使用量造成伤害、获得格挡或多次生成效果；另一套牌负责跨回合储存资源。

### 6. 回响连锁

能力让每回合前若干张牌额外完整结算，核心单卡还拥有 Replay；费用只付一次，但每次结算都会产生合法事件供其他能力响应。

### 7. 免费窗口

姿态或能力让每回合前若干张牌免除能量，也可只免某类资源；高费牌围绕免费窗口安排牌序。

### 8. 动态牌库改造

选择手牌最左、最右、随机或手选目标，改变其伤害、格挡、欲望或状态层数；再用补丁决定强化只持续本回合、本场或整局。

### 9. 附着成长

给关键卡添加 Enchantment 形成长期核心，敌人则添加会提高费用、禁止出牌或在弃牌时反噬的 Affliction；通过特定行为解除负面附着。

### 10. 姿态切换

不同姿态提供互斥的伤害、资源或出牌规则，切换时执行进入与退出效果；构筑围绕何时离开当前姿态做决策。

### 11. Orb 运转

充能多个有独立内部值的 Orb，每回合被动生效；主动激发或用新 Orb 挤出旧 Orb产生爆发，并用技能调整槽位与 Orb 数值。

### 12. 召唤军团

召唤物拥有多个加权行动和自身触发器，部分援护攻击，部分按优先级输出。通过提高容量扩展战场，或主动利用“超过当前容量时最旧单位被击杀”触发退场收益。

### 13. 多敌控制

单体牌锁定活动目标，群体牌攻击全部敌人，随机多段每击重新选靶；控制牌选择最低生命或指定敌人，避免把伤害浪费在已经倒下的目标上。

### 14. 敌人增援与分裂战

敌人被动在特定阶段召来正式增援，或在被击杀时分裂为多个新实体；玩家需要用群体输出、行动顺序控制和处决规则处理战场。

### 15. 诅咒污染与风险收益

敌人向手牌和抽牌堆插入临时诅咒；玩家可以消耗、变形或利用弃牌触发把污染转化为资源，同时承担 Affliction 的长期代价。

### 16. 延迟结算

本回合埋下数回合后的爆发或处决，期间用格挡、状态和牌序维持战局；预约事件会在正确阶段按优先级结算。

### 17. 额外回合控制

积累高门槛资源后获得额外完整回合，或强制结束敌方剩余行动；多敌速度、预约效果与回合计数仍按稳定规则推进。

### 18. 欲望终局

普通卡牌围绕欲望压力建立长期计划，满溢时触发足以决定战局的强力状态、召唤、资源爆发、额外行动或明确终局，而不是获得少量普通数值。

以上体系可以互相交叉。例如“弃牌 + 召唤”可以让弃牌事件强化召唤物；“Orb + 多资源”可以让 Orb 激发返还另一种资源；“多敌 + 状态引爆”可以先群体叠层再逐个处决。

## 二十、当前边界

- 多玩家、队友目标、跨玩家牌区与共享计数器暂不实现。
- 运行时召唤物不由第二轮变量模型直接写入 `battle.summons`；只能由结构化召唤效果生成。
- 普通召唤物与正式敌人是两套容器：只有正式敌人参与敌方全灭胜利判定。
- 每阵营基础召唤容量为 3，可动态增加且没有固定总硬上限；正式敌人同时最多 12 个、整场累计最多 64 个。
- 卡牌直接数值修改只改变伤害、格挡、欲望和状态层数，不改变命中次数。
- 条件与公式使用受限表达式，不执行 JavaScript，也不允许任意函数。
- 自定义状态、资源和卡牌模板必须先注册；运行时不会根据名称猜测隐藏效果。
- Event 的叙事终止是受控入口；普通攻击牌、技能牌、遗物或状态不能用叙事文字绕过战斗结算。

## 二十一、内容设计自检

设计一套新内容时，至少检查：

1. 每个中文描述都有对应的可执行效果，效果标签不会与描述冲突。
2. 自定义状态和资源都在首次引用前注册。
3. 目标视角清楚：卡牌、敌人、召唤物的自身与敌方没有混用。
4. 构筑有输出、节奏和终局，但不强制必须拥有格挡或治疗。
5. 高稀有度提供规则潜力，不只是堆更多无关数字。
6. 敌人拥有可读意图和可结束战斗的路径，不靠无限拖延。
7. 欲望满溢效果与触发难度匹配，足以逆转或决定胜负。
8. 生成、复制、成长和附着的作用域明确，不会每轮重新初始化长期内容。
9. 多敌、召唤和延迟效果都有稳定行动顺序与容量边界。
10. 所有手选操作允许取消，任一步失败都能完整回滚。
