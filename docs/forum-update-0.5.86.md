# 帖子更新记录（可直接发布）

#### 版本更新记录：

- beta0.0.1:
  - 早期测试版本。
- beta0.0.2:
  - 修复重复领取卡牌，开局身份，自定义按钮问题（待完善），新增未读取敌人报错。
- beta0.0.3:
  - 修复自定义按钮无法点击，第二次以后的敌人无法正常注册。
- beta0.0.4:
  - 修复删卡问题，重新处理升级和删卡增加机制，修复 block 动态变量无法获取问题。
- beta0.0.5:
  - 精简代码，修复大量 bug，修复弃牌逻辑错误，修复敌人意图逻辑错误，新增敌人意图模式：先轮训，再概率循环（类似咔咔，未测试）。
- beta0.1.0:
  - bug 修复，完全重构世界书，稳定性增强，但缺乏测试，增加等级表现相关描述。
- beta0.1.1:
  - 世界书优化（感谢 @.a_yu. 提供建议）。
  - 修复战斗中状态不能点击查看、通用页面势力和 buff 显示错误、奖励领取后没有及时刷新、战斗页面不渲染正文、修饰符 buff 未生效、narrate 不兼容单引号等问题。
  - 优化奖励页面等级渲染、卡牌领取缺少 cost、隐藏无用选项以减少 token。
- beta0.1.2:
  - 修复叙事事件不支持单引号、选择器无效、敌人能力失效、敌人护盾无效、战斗结算时部分内容未执行。
- beta0.1.3:
  - 新增护盾获取、消失时触发条件、眩晕效果，优化代码。
- beta0.1.4:
  - 新增 buff 的更多用法，可实现毒爆、清算等效果；新增 ALL 目标，作用于敌我双方。
  - 优化战斗日志，修复 battle_start 效果和遗物被动效果不生效。
- beta0.1.5:
  - 增加 HP 和 lust 的恢复说明，会随剧情自然恢复，避免杂毛注册为 NPC。
  - 战斗结束增加重新开始按钮，修复 stack 语句、抽牌随机性、永久状态显示和选项错误。
  - 优化状态显示。
- beta0.1.6:
  - 重做普通页面和战斗页面 UI，适配手机，增加暗色调切换按钮，修复道具无法使用问题。
- 重构版 0.5.86（beta0.1.6 之后的整体重构）：
  - 全面迁移为浅层 JSON + 简易公式，删除旧字符串效果语法和多套兼容解析器，降低 AI 输出难度和 token 消耗。
  - 重构卡牌、状态、遗物、敌人行动、回合、快照和奖励事务；增加内容预检、公式校验、坏候选隔离、卡组可玩性检查和原子结算。
  - 普通正文不再被 UI 包裹，只在正文末尾追加一个可交互状态栏；战斗页面仍显示在战斗引导正文之后。
  - 重构 SillyTavern + Tavern Helper + MUV 链路，使用轻量正则壳和角色卡内嵌运行时，历史楼层不重复渲染。
  - 普通剧情、普通战斗、战后奖励、经验升级、剧情选项续写、整页刷新恢复均完成真实酒馆验收。
  - 远征改为可选入口，普通模式不会自动生成路线、营火、商店或 Boss。
  - 卡牌处理后端与战斗后端拆分为可独立构建的 portable 包，可供网站、服务端或 Mod 复用。
  - 角色卡支持 `chara_card_v3`，内嵌世界书、7 条角色正则、MVU 变量脚本和角色运行时脚本；官方酒馆导出往返后数据仍完整保留。
  - 当前实机基线：SillyTavern `1.18.0`、Tavern Helper `4.9.3`、MagVarUpdate `v0.181.0`。
  - 角色显示名更新为 `魔法少女世界 0.5.86`，避免与旧版同名卡共存时酒馆助手复用旧脚本状态。
  - 修复开始页重复出现两个加载框，以及普通状态栏在酒馆暗色主题下样式近似丢失、黑字难以阅读的问题。
  - 根目录角色卡已同步为最终 Tavern 兼容卡，内含 14 条世界书、7 条正则和 2 个角色脚本。

导入后首次使用时，请选择最新的 `魔法少女世界*.png`，确认导入内嵌世界书；酒馆助手脚本页面需要切换到“角色脚本库”，并确认当前角色脚本总开关已开启。项目自动导入器会同步登记该许可；手动导入时这是酒馆助手的安全确认步骤。
