## 1.0 正式版更新汇总（相比 beta0.2.1，当前版本 1.0.2）

这次最大的更新，是正式开放了可以在同一个酒馆楼层里连续游玩的爬塔模式，并加入配套的设计辅助器插件。从开局、选路线到战斗、领奖、通关，形成一整局完整的卡牌冒险；世界、角色和构筑方向仍然可以自由设定。

- **新增专属插件「魔法少女世界设计辅助器」。** 负责爬塔后台生成、同层进度管理、卡组分析和敌人设计辅助，并结合当前构筑与所选难度提供设计参考。开始页和设置栏可以检测、安装或更新插件。爬塔模式需要安装，剧情模式仍可不装插件游玩。
- **支持真正的同层连续游玩。** 爬塔的开场剧情、初始牌组、馈赠、地图、战斗、事件、商店、奖励和结算都在当前酒馆楼层内衔接，不用每走一个节点就新增一条聊天消息。刷新后可恢复本局已保存的路线与进度，历史剧情折叠保留。
- **正式开放三幕爬塔。** 每幕都有独立的开场剧情与馈赠，从三条入口选择路线，途经普通战斗、精英、问号事件、宝箱、营火和商店，最终挑战幕末首领。副本会围绕开局设定规划主题、敌人体系和三幕递进，玩法不限定在魔法少女题材。
- **新增后台预生成。** 阅读剧情、挑选馈赠和处理当前节点时，后台会提前准备可达路线的后续内容；战斗奖励也会提前准备，胜利后直接进入选择。后台工作通过设置悬浮球提示，减少反复弹窗打断阅读。
- **开局设定和流派选择更自由。** 可分别填写角色、世界、故事、开场、卡组和本局额外要求，并保存为自己的开局预设。新增可搜索、跨类别多选的机制菜单，包含12类、138项基础机制；可以自由组合，也可以直接写想玩的构筑。开局剧情、玩家资料、初始牌组和启程馈赠由一次生成共同完成。
- **新增围绕构筑取舍的路线玩法。** 馈赠可以带有代价，也能筛选、强化或转化当前牌组；问号房可能遇到事件、战斗或商店。部分事件会隐藏卡牌身份与收益，选择后才揭晓。营火可在休息、锻炼、搜刮、回忆中四选一，商店支持连续购买和付费删卡，还可能重新遇见本局错过的牌。
- **完善复杂构筑与敌人协作。** 在已有召唤、姿态、资源、法球等玩法上，进一步完善召唤援护、友军保护、群体增益、指定卡牌强化和永久成长。部分强化可以延续到未来获得的同名牌，让一局中的构筑能够持续发展。
- **重做爬塔页面和内容详情。** 剧情与当前操作、路线、角色状态分区展示，直接查看卡组、遗物、道具、能力和欲望效果。手牌、奖励、牌组与详情统一卡面，复杂效果分组说明，关联的状态、姿态和召唤物可点击查看；继续优化手机排版、长文本和页面定位。
- **新增难度设置与通关结算。** 开局和设置栏可以调整爬塔难度，查看卡组分析及战斗强度记录。打通第三幕后进入作者鱼结局，可以用本局累计敌人评分给正在改代码的鱼来上最后一击。
- **改进生成修复与问题反馈。** 生成失败时可在当前页面查看原因并重试，自动修复尽量保留已经成立的角色、剧情和卡组，只处理出错部分。排查导出补充模型原始返回与错误记录，方便反馈开局和节点生成问题。
- **合并最新1.0.2修复。** 修复开局馈赠引用已有卡牌导致生成失败、部分浏览器环境无法完成开局保存，以及初始化和重试时剧情区、状态栏提前显示的问题，并修正部分姿态条件的中文说明。

**更新与使用：** 导入并选择「魔法少女世界 1.0.2」，同时导入新卡内嵌的世界书，启用酒馆助手与卡内角色脚本。游玩爬塔模式时，将「魔法少女世界设计辅助器」安装或更新至1.0.2后刷新酒馆。由beta0.2.1升级的玩家，建议新开一局体验完整流程。
