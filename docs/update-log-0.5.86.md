# 0.5.86 更新日志

这是一版从 `beta0.1.6` 之后开始的整体重构版。公开版本记录不虚构中间 beta 号，内部构建号固定为 `0.5.86`。

## 核心重构

- 从旧的字符串效果解析迁移到浅层 JSON + 简易公式；AI 只输出 `effects` 和 `discard_effects`，运行时统一编译为类型化 `EffectProgram`。
- 清理旧 `effect`、`discard_effect`、`effect_program`、`ME/OP/ALL`、字符串条件和字符串选牌器入口，减少 AI 记忆负担和维护分叉。
- 新增内容契约、公式校验、候选奖励校验、卡组可玩性预检和精确错误路径；坏卡只禁用自身，不阻塞同批有效候选。

## 酒馆链路

- 以真实 SillyTavern `1.18.0` + Tavern Helper `4.9.3` + MagVarUpdate `v0.181.0` 为发布基线。
- 角色显示名版本化为 `魔法少女世界 0.5.86`，避免旧版同名角色卡切换时 Tavern Helper 复用旧脚本状态。
- 本地酒馆导入器会同步登记 `character_allowed_regex` 与 Tavern Helper 角色脚本允许列表；手动导入到其他酒馆时仍需首次确认内嵌世界书并开启当前角色脚本。
- 正文保持 SillyTavern 原生渲染；普通剧情只在末尾追加一个状态栏，战斗页继续位于战斗引导正文之后。
- start/common/fish 改为轻量酒馆正则壳，完整运行时放入角色卡酒馆助手脚本，历史楼层不重复挂载完整 iframe。
- MUV 变量读写绑定当前消息楼层，战斗快照、刷新恢复、战斗终态和奖励结算均经过真实酒馆回归。
- 普通剧情和普通战斗默认 `run=null`；远征入口仍是可选功能，只有玩家主动点击才创建路线。
- 修复 `[开始游戏]` 后接 MUV 状态占位符时 start/common 同时命中、开始页出现两个加载框的问题。
- 修复状态栏 iframe 不继承 SillyTavern 暗色主题以及旧主题缓存锁定亮色的问题；现在自动匹配酒馆背景，手动切换仍会记忆。

## 可玩内容

- 完成首轮角色创建、普通剧情、普通战斗、卡牌/状态/遗物/敌人行动、战后奖励、经验升级、剧情 Option 续写和刷新恢复闭环。
- 战后奖励支持卡牌、道具、经验和非法候选隔离；领取有效奖励后候选清空，剧情选项自动恢复。
- 新增可独立构建的 `card-backend.mjs`、`battle-backend.mjs` 和 `magic-girl-core.mjs`，不依赖 Tavern、MUV 或 DOM。

## 使用注意

导入后请在角色管理中选择最新的 `魔法少女世界*.png`，确认“导入角色卡的世界书”；Tavern Helper 的脚本页要切换到“角色脚本库”，不要把空的全局/预设脚本库当成角色脚本丢失。

MVU 额外模型解析不属于本版，记录在 `docs/future-mvu-extra-model.md`，后续单独评估。
