# 论坛版本更新记录：beta0.5.92

- beta0.5.92：
  - 重构为严格的“剧情主模型 + MVU 额外模型”两阶段链路。主模型只负责角色扮演和敌人描述，额外模型再根据剧情生成卡牌、敌人、奖励和变量数据，减少模型同时处理剧情、公式和更新命令时的偏移。
  - 战斗开始改为先输出待注册标记，只有敌人名称和行动数据校验通过后才显示战斗页，不再出现剧情刚遇敌就提前打开空战斗或使用错误敌人数据的问题。
  - MVU 默认启用额外模型解析、自动请求和兼容假流式，并默认复用当前酒馆主模型；剧情世界书和变量世界书已完全分开。
  - 删除 AI 生成选项。剧情由玩家自由输入推进，程序奖励选择仍保留。
  - 正文不再包进 UI，只在末尾显示可交互状态栏；状态栏默认保留最近三层，并恢复初版暖白少女日记和彩色书签风格。
  - 修复暗色酒馆中状态栏主题变量失效、黑底文字不可读的问题。
  - 战斗 UI 重做为“敌人 / 手牌 / 我方”单屏布局，桌面和手机均无需上下滑动；手牌不再出现横向滚动条，并会随分辨率自动重排。
  - 修复电脑端卡牌无法可靠拖动出牌。鼠标和触屏现在使用同一套拖牌逻辑，同时保留点击出牌模式。
  - 战斗日志和战后 AI 上下文统一，结算后会提供更完整的回合事件、最终数值和牌区信息，便于 AI 续写战后剧情。
  - 远征暂时保留为可选实验入口，后续单独重做；本次优先完成剧情、变量、状态栏和普通战斗主线迁移。
  - 清理旧选项协议和孤立兼容脚本，补充完整项目文档、MVU 职责文档、酒馆踩坑记录与 token 测量工具。
  - 最终角色卡已在 SillyTavern 1.18.0 完成官方导入、内嵌世界书、状态栏、桌面/手机战斗布局、拖动出牌和战斗日志实机验证。为避免酒馆同名卡缓存污染，本版角色名为“魔法少女世界 0.5.92”，请作为新角色导入，不要覆盖旧版本。
