# 战斗 UI 与战后交接验收：0.5.138

## 本轮结果

- 战后弹窗使用星空暗色面板；胜利为绿色、失败为红色、终止为灰蓝色，不再使用白色通用弹窗。
- 弹窗提供 500 字可选的战后行动输入，确认后与战报一起发给剧情模型，发送失败会保留输入并恢复按钮。
- 战报保留全部回合，每回合一行。重复出牌、敌方行动、遗物、能力和状态触发均压缩为“名称×次数”。
- 战报末尾单独列出完整卡组、遗物、能力及来源、道具、双方欲望效果、敌方行动、最终属性、状态和牌堆；不把每段伤害流水或奖励模型内部指令发给剧情模型。
- 桌面出牌由 Pointer Events 接管，不启用 HTML `draggable`；单张卡牌具备抬起、跟手倾斜、光泽、投放高亮、成功飞向战斗舞台和取消回弹，不会拖出整个手牌容器。
