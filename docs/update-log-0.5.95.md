# 0.5.95 更新记录

## 开始页自由配置

- 只需选择“剧情模式”即可开始，阵营、身份、地点、世界观、剧情和卡牌偏好全部可选。
- 用户没有填写的项目不会生成空字段；最小交接只有一行浅层 JSON：`{"mode":"story"}`。
- 移除职业候选卡、城市地点选择器以及剧情方向、节奏和语气预设。职业、身份和开场地点改为自由文本，剧情页只保留一个自由输入框。
- 白木市的城市、地点和旧职业资料仍保存在源码中，当前开始页不再强制使用，之后可供世界内容和爬塔模式复用。

## AI 与 MVU

- 第一阶段剧情 AI 会自然补全用户未填写的身份、地点、能力主题和开场目标，不暂停剧情追问配置。
- 第二阶段 MVU 接受只有 `mode` 的最小配置，并以开场正文为事实来源完成职业、地点、牌组和其他初始变量。
- 角色卡及内嵌世界书升级为 `0.5.95`，避免 SillyTavern 复用旧版同名缓存。
