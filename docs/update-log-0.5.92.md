# 0.5.92 更新记录

## 模型与 MVU

- 主模型与 MVU 额外模型完全分工：主模型只写剧情并读取构筑信息，不再输出变量、JSON、公式或选项；额外模型根据已完成剧情更新变量。
- 战斗改为两阶段交接。主模型先描写敌人并输出 `<BATTLE_PENDING>`，额外模型注册可执行敌人后，运行时校验成功才转换为 `<BATTLE_START>`。
- MVU 默认启用额外模型解析、自动请求和兼容假流式，默认复用酒馆当前主连接；`[mvu_plot]` 与 `[mvu_update]` 世界书已严格拆分。
- 删除 AI 生成选项及旧 `<Options>/<Option>/<BattleOption>` 前端解析链。玩家继续使用自由输入，奖励仍由程序选择。

## UI 与交互

- 正文保持 SillyTavern 原生显示，普通状态栏只追加在正文末尾，并默认渲染最新三层。
- 修复角色运行时合并 CSS 时残留 BOM，导致真实酒馆忽略 `:root` 主题变量、状态栏在暗色酒馆中变成黑底散落控件的问题。
- 恢复初版暖白少女日记和彩色书签设计，不再维护暗色主题分支。
- 战斗页重写为一屏横向卡牌游戏结构：敌人在上、手牌居中、我方在下；桌面与手机都不需要上下滑动。
- 删除手牌横向滚动；按可用宽度重叠卡牌，并在窗口或横竖屏变化时重新排版。
- 出牌从 iframe 中不稳定的原生 HTML5 drag/drop 改为统一 Pointer Events；桌面鼠标和触屏共用一套实现，点击模式仍保留。

## 战斗与维护

- 战斗页面日志与战后剧情上下文复用同一事件流。战斗结束会携带结果、最终生命/欲望/牌区计数和最多 36 条事件。
- 远征继续作为可选实验入口，本版本停止扩展，普通剧情和普通战斗不创建或依赖 `run`。
- 删除仍依赖旧 AI 选项语法的孤立实机审计脚本，避免旧协议重新进入维护链。
- 新增世界书角色 token 测量命令，并补充最终架构、MVU 边界和酒馆踩坑文档。

## 发布验证

- 最终卡已通过 SillyTavern `1.18.0` 官方接口导入，酒馆能识别、导入并链接内嵌世界书 `魔法少女世界0.5.92`；卡内包含 17 条世界书、7 条正则和 2 个启用脚本。
- 状态栏已在真实酒馆验证暖白主题、最近三层和无 AI 选项；战斗页已验证桌面/手机无页面滚动、分辨率变化后手牌重排、拖动出牌与详细战斗日志。
