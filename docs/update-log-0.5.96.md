# 0.5.96 更新记录

## 首轮卡组初始化

- 第一轮无论是否直接进入战斗，都必须先建立 `battle.cards`、遗物、道具、欲望满溢效果、核心资源和等级，再注册敌人。
- 明确卡牌只能写入 `battle.cards`；`battle.player_abilities` 只用于带触发条件的本场被动能力。
- 增加运行时纠偏：若 AI 把具有完整卡牌字段的对象写入 `player_abilities`，会在 MVU 更新结束时迁移到 `battle.cards`，不会污染真正能力。
- 玩家初始战斗内容不完整时不再提前生成 `<BATTLE_START>`，状态栏会显示原楼层修复入口。

## 原楼层 MVU 修复

- 战斗页和状态栏的修复按钮不再创建新用户消息，也不调用剧情主模型。
- 修复标记临时写入当前助手楼层，并调用 MVU 自带的“重试额外模型解析”事件；完成后清理标记并刷新同一楼层。
- 玩家内容和敌人同时错误时，会在一次第二轮模型请求中同时激活对应修复规范。
- 修复失败会恢复点击前的消息和变量快照，避免留下半更新状态。
