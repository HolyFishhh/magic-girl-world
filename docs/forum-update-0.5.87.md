# 论坛版本更新记录：beta0.5.87

- beta0.5.87：
  - 修复 SillyTavern 远程环境开始页 `Unexpected token '<'`，bootstrap 改为 ES5 兼容并增加酒馆助手二次解析门禁。
  - 角色卡改为单一交付文件：根目录 `魔法少女世界.png`。发布器、导入器和校验器统一使用根目录卡，删除 `dist/tavern` 中重复 PNG，避免导入旧世界书和旧脚本。
  - 开始页新增模式选择：先选剧情模式或远征模式。剧情模式不创建远征；远征模式在初始战斗内容通过校验后由程序自动创建路线。
  - common 状态栏默认保留最近三层：最新层可以操作，前两层只读，超过三层自动卸载；战斗页面仍只显示最新层。
  - 移除暗色模式和主题切换按钮，恢复浅色少女日记风格，避免酒馆暗色外壳透入造成文字不可读。
  - 修复职业状态更新把完整 JSON 对象直接显示的问题，拆分显示职业名和职业能力变化。
  - 接入 MagVarUpdate 额外模型解析：默认沿用酒馆主模型执行变量轮次，用户可在 MVU 设置中选择独立模型；API Key 不写入角色卡。
  - 世界书条目增加 `[mvu_plot]` / `[mvu_update]` 分类，减少主模型同时生成剧情正文和完整变量命令的负担。
  - 更新项目结构、酒馆助手踩坑记录、MVU 配置说明和可移植卡牌/战斗后端文档。
