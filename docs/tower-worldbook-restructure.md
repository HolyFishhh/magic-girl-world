# 世界书重组清单（剧情 / 爬塔隔离）

本文记录条目职责、导入顺序与隔离验收。当前正文已经按下列分区整理；`worldbook_new/README.md` 是目录内的维护索引，`manifest.json` 与 `entry-config.json` 的顺序是实际导入顺序。

## 已落实的边界

- 剧情正文、末行交接、MVU 命令语法、变量路径形状、效果 DSL、首次初始化、遇敌注册、战斗结算和两类修复均各有一个详细权威条目。
- 常驻 MVU 规则只负责完整快照、普通增量与专用事务路由，不再复制战后候选清单或完整敌人对象规范。
- 共享条目已移除旧路线、事件、营火与商店触发词；爬塔内容只由两个扩展后台专用标记激活。
- 普通剧情上下文不注入模式与爬塔运行态，也不包含爬塔短叙事规则；爬塔后台协议明确不适用于剧情正文。
- `[initvar]不要启用` 保持关闭，仅作为 MVU 初始化模板读取。
- 技术文档只保留字段形状与抽象机制边界，不提供固定题材、角色、卡牌、敌人或固定数值模板。

## 目标分区

1. **模式入口**
   - 首次角色创建与初始化。
   - `game_mode_lock` 是唯一模式来源；禁止从普通聊天关键词推断或切换模式。
2. **剧情模型通用**
   - 剧情正文职责、当前长期状态、世界/NPC 连续性、战后续写。
   - 剧情模式保持自由输入和完整篇幅；不读取爬塔的短叙事规则。
3. **MVU 数据契约**
   - 变量结构、增量更新、卡牌常驻、输出标签。
   - 程序独占字段集中列出一次，避免在多个条目重复声明。
4. **战斗内容生成**
   - 通用效果 DSL、卡牌/敌人/状态/遗物/道具契约、目标视角、复杂机制。
   - 只描述可执行能力与边界，不放绑定题材、角色或固定数值的硬例子。
5. **战斗结算与修复**
   - 胜负结算、战后剧情输入、初始化修复、自然语言卡牌修复。
6. **爬塔专用**
   - 仅在 `game_mode_lock.mode=tower` 的扩展后台请求启用。
   - AI 只填程序指定节点内容；不生成地图、不修改路线、不提前公开战斗奖励。
   - 短过场、开局馈赠、事件、商店、宝箱、营火、普通敌人、精英、Boss 分型契约。
7. **末端终检**
   - 检查模式边界、增量写入、中文说明、视角和程序独占字段。

## 验收

- 相同剧情模式种子在重排前后，不出现短叙事、自动路线或爬塔节点协议污染。
- 爬塔后台请求只加载当前节点对应的最小分型契约；第二轮仍能读取完整 MVU。
- 每个变量字段只有一个权威结构定义，每个生成阶段只有一个入口。
- 不写用户提供的具体卡牌、敌人、角色或固定数值例子。
- 世界书契约、MVU 契约和开始流程测试通过；角色卡构建、导入与真实 SillyTavern 请求仍按总实施计划统一验收。
