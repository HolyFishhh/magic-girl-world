# 0.5.149 更新记录

## 战斗界面

- 敌方行动栏只显示行动名称，点击后再展开描述与完整效果，避免多效果行动挤压标题区域。
- 敌人头像上方新增下一回合意图摘要；伤害、欲望、格挡、自定义状态等以图标和数值组合显示。
- 手机端顶部工具栏改为按实际内容分配空间，牌组、抽牌堆、弃牌堆、消耗堆和全屏按钮不再使用互相挤压的等宽布局。
- 恢复卡牌稀有度对应的底色、边框与光效，并重新约束不同稀有度的生成强度与构筑价值。

## 生成与玩法

- MVU 第二阶段最大回复长度提升至 20000，减少复杂初始化和战斗内容被截断的情况。
- 战后剧情生成必须覆盖每个实际回合，将战斗摘要整理为连贯剧情后再继续推进。
- 扩展通用牌区选择、卡牌数值修改、卡牌重复结算与免能量规则的运行时基础和校验。
- `initvar` 继续作为关闭的世界书条目供 MVU 初始化读取，不会进入普通剧情提示。

## 发布验收

- 类型检查、战斗交互、世界书与 MVU 契约、生产构建和角色卡契约均纳入发布门禁。
